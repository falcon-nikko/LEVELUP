# LEVELUP

**Domina las habilidades de la nueva economía digital en 10 minutos al día.**  
*Master the skills of the new digital economy in 10 minutes a day.*

LEVELUP es una plataforma bilingüe (**ES / EN**) de micro-aprendizaje interactivo y ejecución práctica con diseño **Minimalista Tech (Clean Pro)**. Combina mecánicas de hábito estilo Duolingo con misiones ejecutables del mundo real y un doble motor de monetización (**Suscripción LEVELUP PRO + Afiliados Contextuales**).

## Rutas Principales (Career Tracks)
1. **AI & Automation** — Prompt Engineering, flujos con Make/n8n y Agentes IA.
2. **Modern Coding** — JavaScript, Python, APIs, SQL y Vibe Coding para Micro-SaaS.
3. **Smart Dropshipping** — Validación con datos, Unit Economics (ROAS/CPA), tiendas y UGC.
4. **Digital Agency (AAA / SMMA)** — Ofertas B2B, Cold Outreach y cierre de ventas.
